Extension test harness

This page pretends to be a streaming player. It uses the same DOM shape and class names Netflix uses, so the extension treats it as the real thing — which means you can check the whole flow works before going near your Netflix account. Nothing here touches Netflix, and no login is involved anywhere.

If the extension is working you will see a LEXICON bar with the same line rendered underneath, with content words underlined. Click one and it turns green, and it appears in your deck at localhost:4000.
